The design tree

Every number lives in exactly one place and flows downhill. Here is the whole of it — which file owns what, and what moves when you change it.

DESIGN_TREE.html in the repo. It is updated alongside the code, not after it: if a document gains a figure or a script starts reading one, this page changes in the same sitting.

The three rules that explain everything else

1 · Documents own figures
spec/ holds one document per off-the-shelf component — what a thing is. Allowances between parts live apart, in fits.md, because a gap is a property of the joint, not of the glass.
2 · Code reads documents
specs.py parses any markdown table whose first column is Key. Scripts call specs.figure(doc, key) instead of holding their own copy of a number.
3 · Parts derive, never restate
Each model is built from the one above it. bowl.py takes its cavity from base.py, so the cradle cannot drift from the vessel it has to fit.

Every file, by the job it does

Specifications

  • spec/vessel.mdThe glass, as confirmed. Four keyed figures — overall_height joined them on 2026-08-09.
  • spec/fits.mdWhat to leave between parts. All figures radial.
  • spec/led_ring_light.mdThe bought light. Seven keyed figures; imperial converted once, here.
  • PRINT_LOG.mdWhat was actually printed and whether it fitted — the evidence behind every Confirmed date.

Shared code

  • specs.pyReads the documents.
  • engrave.pyPuts labels on parts.
  • print_volume.pyThe 180mm bed, plus the fit check that refuses to export an oversize part. bounds() is the honest way to measure a curved part — vertices under-report an arc, and did so by 1.7mm here.

Printed parts

  • test_fits/bowl.pystepThe cradle. Floorless, fits.
  • test_fits/cradle_segment.pystepA 45° arc of that cradle, cut from where the build plate never reaches, for comparing the seat's curve against the glass.
  • test_fits/profile_gauge.pystepA 25.9 × 179.4 × 1mm swatch with the vessel's whole side profile cut out of one edge, cut with the vessel solid itself. Stands on the table beside the tank, so z=0 is the same plane for both and every junction height is a comparison rather than a measurement. Outline corners rounded R1 for the 0.4mm nozzle; exported lying flat, labels up.
  • led_sun_lid/lid.pystepThe sun dial lid, master version.
  • led_sun_lid/lid_two_spoke.pystepThe two-spoke variant.
  • lid_screen/screen.pystepThe screen. Exports three files — both bodies together, then each alone, so they can take different print settings.

References & previews

  • test_fits/base.pystepThe vessel itself, modelled to check things against.
  • led_ring_light/ring_light.pystepA mock of the bought light, for clearances. Not printed.
  • vessel/vessel.pystepThe tank’s exterior, measured off a photograph: five diameters, blended, on an R8 base roll. Each zone carries its own diameter engraved on it. Four junctions are tangent-arc pairs; the rim flare is a cone with end fillets, because an arc pair cannot span dr/dz > 1 without folding.
  • assembly.pyno exportThe whole stack in the viewer.
  • test_fits/tube.py · led_ring.pystepStandalone trial rings. Nothing derives from them.

Loose ends, so they don't surprise you

  • Every figure is now wired. The ring light was the last one holding its dimensions in two places; as of 2026-08-08 both ring_light.py and lid.py read them from the document. Reading the document's 89.3572 rather than computing 3.518 × 25.4 shifted the parts by about a millionth of a cubic millimetre — solver noise, not a design change, and the print is unaffected.
  • The base corner radius is settled at 8mm — by printing 45° cradle sections and holding them against the glass until the curve matched. That is a visual match, not a caliper reading, but it is evidence about the object rather than about a photograph.
  • The vessel model is photo-derived and locked, not measured. One image, scaled by the one confirmed diameter. Good to a percent or two on the diameters; the lower waist is the weakest part, since the substrate line crosses it in the picture and I overrode the outline there to match the upper waist. It is deliberately not written into spec/vessel.md — that document holds confirmed figures, and a second copy of these would drift.
  • The rim flare folded back on itself until 2026-08-09. A tangent-arc pair spans dr/dz = tan(alpha/2) and so tops out at 1; the waist→rim junction needs 1.266, and asking for it turned each arc past horizontal and left a re-entrant groove 0.17mm tall and 1.5mm deep under the rim. Renders never showed it. A horizontal slice through it returned two solids, which is how it was caught — by measuring, not by looking. That junction is now a cone with R1.5 ends; nothing else moved.
  • The gauge gives up the bottom 2mm of the profile on purpose. The base roll meets the table tangentially, so the swatch ran out to a feather there — zero thickness at r=81.0, and not one extrusion width until r=83.5. A fillet cannot round that corner because it has no included angle, so the tongue is trimmed at r=86.29, where a plain cylinder goes tangent to the roll and nothing above it moves. The z=0 datum survives intact: the swatch still stands on a 20.9mm full-width foot. What it costs is the one stretch of profile already confirmed by other means.
  • Nothing about the profile is confirmed yet — the gauge is what would confirm it. The swatch is modelled, verified and exported; it has not been printed or held against the glass. Until it is, the five diameters and all five junction heights remain photo-derived, and a fit anywhere on it will only be evidence about the bands that actually touched.
  • The measured height broke the photo model, and the repair is proportion rather than measurement. A rule says 179.39mm; the outline said 156.4, short by 14.7%, because the brim runs off the top of the frame. Heights above the base roll are scaled by Z_SCALE to close it — 1.155, taken over the stack above the crest rather than the 1.147 the two totals imply, because the roll is a confirmed R8 circle and scaling z through it would make it an ellipse. Diameters are untouched: the base OD that sets them is confirmed on its own. So every junction height is now the photograph's share of a real total. Better than it was; still not measured.
  • The cradle's seat now tapers to nothing. Removing the floor left the inner lip meeting the bed tangentially at r=84. It fits, but treat that lip as the fragile edge when handling the print.
  • The constant-stiffness work is gone from the working tree, not lost — the moment integration and the solved floor profile are in the git history, and the method is written down.
